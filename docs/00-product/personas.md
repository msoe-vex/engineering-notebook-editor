# Personas

| Persona | Goals | Typical roles in product |
| --- | --- | --- |
| **Student / writer** | Write dated design entries, images, compile PDF | Org `member`; notebook access |
| **Team lead / mentor** | Review schedule, phases, roster credits, audits | Org `admin` or notebook-restricted grant |
| **Org admin** | Invite people, manage teams ACL, create notebooks | Org `owner` / `admin` |
| **Platform admin** | Grants (e.g. Vertex AI), metrics, user ops | `service_admin` (`platformRole`) |

Personas map to permissions described in each FR and in [tenancy-acl.md](../02-architecture/tenancy-acl.md).
