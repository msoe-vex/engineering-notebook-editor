# UI kit

Prefer these over ad-hoc Tailwind controls. Visual reference: Entries explorer (`NotebookEntryList`).

| Component | Use for |
| --- | --- |
| `Button` / `IconButton` | Actions |
| `TextField` / `TextArea` / `Select` | Form fields |
| `Checkbox` / `Switch` | Boolean controls |
| `Chip` / `Badge` | Tags / status |
| `FormSection` | Settings groupings |
| `ImageField` | Upload / replace / remove image |
| `Dialog` | Modals |
| `ConfirmationDialog` | Destructive / leave confirms (not `window.confirm`) |
| `TabNav` | Page tabs (`icon` optional) |
| `DropdownMenu` / `ContextMenu` | Menus |

Keep user copy short: label the control; don’t narrate architecture.
