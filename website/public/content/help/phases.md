# Design phases

Phases tag entries in the engineering design cycle so judges (and teammates) can follow the narrative.

## Defaults

Typical seasons use labels such as **Identify**, **Brainstorm**, **Select**, **Build**, **Test**, and **Evaluate**. Exact names and colors are configured per notebook in **Setup**.

## Using phases

- Set a phase on each entry from the header picker.
- Explorer glyphs use the phase icon/color when set; templates use a template glyph instead.
- Filter the explorer by phase when preparing a design story for competition.

## Tips

- Prefer one clear phase per entry; split long days into multiple entries if the work spans stages.
- Keep phase names stable mid-season so filters and PDFs stay consistent.
- Incomplete metadata (missing phase/date/authors when required) shows warnings in the explorer.
