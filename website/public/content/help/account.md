# Account & security

Manage who you are, how you sign in, and personal preferences.

## Profile

- Display name and primary email come from your identity provider / Better Auth session.
- **Secondary emails** (when available) help match invites after verification.
- Verify your email when prompted; use **Send verification** and wait for the cooldown before resending.

## Linked providers

On **Account**, link Google, GitHub, Discord, or LinkedIn when the deployment enables them. Linked accounts show provider logos and connection state. Dev-only synthetic tokens are for local engineering — not for production teams.

## Preferences

- **Theme** — light / dark / system.
- **Default authors** — prefilled on new entries.
- **GenAI** — enablement, provider, models (keys stay local). See [Generative AI](/help/genai).

## Security basics

- Sign out from the account menu when on a shared machine.
- Do not paste API keys into notebook content or public pages.
- Report suspicious account activity via **Report Issue**.
