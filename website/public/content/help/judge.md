# Judge

**Judge** scores a notebook against a rubric using the GenAI stack. It is meant for practice and coaching — not an official competition verdict.

## Rubrics

- Create or import a rubric on the Judge pages.
- Normalize / extract structure until the rubric is **ready** (categories and criteria populated).
- Edit carefully; trash unused rubrics when done.

## Running a grade

1. Pick a ready rubric and start a score job.
2. Progress shows current status + percent (same quiet pattern as Compile).
3. Open the finished judgment for linked feedback. Entry citations resolve to notebook entries when IDs match.

## Tips

- Ensure competition rules allow AI assistance before using Judge for season work.
- Treat scores as signals; verify every claim against the actual entries.
- Past grades remain listed until you delete them.
