# Backup & ZIP

Cloud notebooks sync continuously. ZIP is an **optional backup / migration** tool, not a live Git sync.

## Export

From the notebook overflow menu, **Export ZIP** downloads entries, metadata, and assets you can archive offline or move between environments.

## Import

**Import ZIP** merges into the open notebook with **last-write-wins** semantics. Confirm you are on the intended notebook before importing.

## What ZIP is not

- Not a substitute for org membership or restricted ACL.
- Not bidirectional GitHub collaboration (legacy local/GitHub modes are retired).
- Not a full audit history — prefer the live cloud notebook as source of truth during the season.
