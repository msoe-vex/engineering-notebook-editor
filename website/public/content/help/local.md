# Setting up a Local Workspace

To use the Local Folder mode, you need a specific directory structure that the editor understands.

## 1. Download the Template

### Option 1: Template Repository

Go to the [Template Repository](https://github.com/msoe-vex/engineering-notebook-template) and download the ZIP file or clone the code.

### Option 2: Export from Editor

Open a new Temporary workspace. Click on the project name at the top of the workspace and select the option to export the data. This will download a ZIP file containing the necessary folder structure and example entries.

## 2. Extract to Folder

Extract the files into a folder on your computer (e.g., "Engineering Notebook 2024").

## 3. Connect in Editor

In the Editor's settings, choose "Local Folder" and select the folder you just created. Every change you make in the editor will be saved directly to your local files, and any changes you make to the files outside the editor will be reflected when you return to the site.

> **Note:** The browser will ask for permission each time you return to the site. This is a security feature to ensure you are in control of your local files.
